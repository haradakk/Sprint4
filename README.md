Aplicativo de Análise de Dados de Veículos

Este projeto consiste em um aplicativo web desenvolvido com Streamlit para realizar uma análise exploratória de dados de anúncios de veículos.
O aplicativo permite explorar o conjunto de dados de forma interativa por meio de graficos

Funcionalidades:

-Histograma interativo mostrando a distribuição da quilometragem dos veículos.
-Gráfico de dispersão mostrando a relação entre o preço e a quilometragem dos veículos.
